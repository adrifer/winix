# Nix backend

The Nix backend targets NixOS, nix-darwin, and Home Manager. It translates evaluated fragment IR into Nix files that the standard Nix toolchain builds and activates.

## Strategy

Winix does not replace Nix evaluation. It generates Nix modules and lets Nix evaluate, build, activate, and roll back. The Nix backend is a **code generator**, not a Nix interpreter.

## Output structure

Generated files live in `.winix/out/` (gitignored, ephemeral, per-machine):

```
.winix/
  out/
    flake.nix                # Thin wrapper referencing hosts and inputs
    flake.lock               # Symlink/copy from project root (shared lock)
    hosts/
      wsl-work.nix           # NixOS system config for this host
      wsl-work-home.nix      # Home Manager config for this host
      macbook-pro.nix        # nix-darwin system config
      macbook-pro-home.nix   # Home Manager config
```

The project root contains the lock (committed, universal):

```
~/dotfiles/
  winix.config.ts
  inputs.ts
  fragments/
  flake.lock               ← committed, shared across all hosts
  .winix/                  ← gitignored
```

## Generated flake.nix

A thin wrapper that declares inputs and references host modules:

```nix
# .winix/out/flake.nix — Generated by Winix, do not edit
{
  description = "Generated by Winix";

  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    nixpkgs-stable.url = "github:NixOS/nixpkgs/nixos-25.11";
    nixos-wsl = {
      url = "github:nix-community/NixOS-WSL";
      inputs.nixpkgs.follows = "nixpkgs";
    };
    home-manager = {
      url = "github:nix-community/home-manager";
      inputs.nixpkgs.follows = "nixpkgs";
    };
  };

  outputs = { self, nixpkgs, nixos-wsl, home-manager, ... }:
  let
    inputs = { inherit nixpkgs nixos-wsl home-manager; };
  in {
    nixosConfigurations.wsl-work = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [ ./hosts/wsl-work.nix ];
      specialArgs = { inherit inputs; };
    };

    darwinConfigurations.macbook-pro = nix-darwin.lib.darwinSystem {
      system = "aarch64-darwin";
      modules = [ ./hosts/macbook-pro.nix ];
      specialArgs = { inherit inputs; };
    };
  };
}
```

## Generated host module

The merged result of all fragments for a host, split into system + Home Manager:

```nix
# .winix/out/hosts/wsl-work.nix — Generated by Winix
{ inputs, pkgs, lib, ... }:

{
  imports = [
    inputs.nixos-wsl.nixosModules.wsl
    inputs.home-manager.nixosModules.home-manager
  ];

  # [platforms/linux.ts] NixOS base platform
  nixpkgs.config.allowUnfree = true;
  nix.settings.experimental-features = [ "nix-command" "flakes" ];
  system.stateVersion = "25.05";

  # [fragments/wsl.ts] WSL integration
  wsl.enable = true;
  wsl.defaultUser = "adrifer";
  wsl.wslConf.interop.enabled = true;
  wsl.wslConf.interop.appendWindowsPath = false;
  wsl.interop.register = true;

  # [fragments/work-sysctl.ts] Kernel tuning
  boot.kernel.sysctl = {
    "net.ipv4.ip_unprivileged_port_start" = 443;
    "fs.inotify.max_user_watches" = 1048576;
    "fs.inotify.max_user_instances" = 1024;
    "fs.inotify.max_queued_events" = 65536;
  };

  # [fragments/wsl.ts] nix-ld
  programs.nix-ld.enable = true;
  programs.nix-ld.libraries = with pkgs; [ icu zlib openssl ];

  # Packages (merged from multiple fragments)
  environment.systemPackages = with pkgs; [
    wl-clipboard
    socat
    bubblewrap
  ];

  # Home Manager
  home-manager.useGlobalPkgs = true;
  home-manager.useUserPackages = true;
  home-manager.users.adrifer = import ./wsl-work-home.nix;
}
```

## Fragment → Nix mapping

| Fragment field | Generated Nix |
|---|---|
| `nixos.packages: ["git"]` | `environment.systemPackages = with pkgs; [ git ];` |
| `nixos.programs.nixLd.enable` | `programs.nix-ld.enable = true;` |
| `nixos.boot.kernel.sysctl: {...}` | `boot.kernel.sysctl = { ... };` |
| `nixos.imports: [inputs.nixosWsl]` | `imports = [ inputs.nixos-wsl.nixosModules.wsl ];` |
| `home.home.packages: ["wslu"]` | `home.packages = with pkgs; [ wslu ];` |
| `home.programs.git.enable` | `programs.git.enable = true;` (inside HM module) |
| `home.home.sessionVariables: { K: "V" }` | `home.sessionVariables.K = "V";` |
| `nix.expr(expr)` | Verbatim Nix expression |
| `rawModule("./file.nix")` | Added to `imports` list |

## Input name mapping

TypeScript camelCase is converted to Nix kebab-case:

| inputs.ts | flake.nix |
|---|---|
| `nixpkgs` | `nixpkgs` |
| `nixosWsl` | `nixos-wsl` |
| `homeManager` | `home-manager` |
| `nixpkgsStable` | `nixpkgs-stable` |

Override with explicit `nixName` when the convention doesn't apply:

```ts
nixosWsl: input("github:nix-community/NixOS-WSL", {
  nixName: "nixos-wsl",
  follows: { nixpkgs: "nixpkgs" },
}),
```

## Package resolution

Packages reference nixpkgs by default. Explicit source selection uses `nix.pkg.stable()`:

```ts
// Default: from nixpkgs (unstable)
packages: ["git", "nodejs"]
// → environment.systemPackages = with pkgs; [ git nodejs ];

// From stable channel:
packages: ["git", nix.pkg.stable("wslu")]
// → environment.systemPackages = with pkgs; [ git pkgs.stable.wslu ];
```

Use `overlay.stable("nixpkgs-stable")` to expose `pkgs.stable.*` from another input.

## Built-in presets and intent helpers

The frontend DX helpers are normal fragments before backend generation:

| Helper | Generated data |
|---|---|
| `platforms.nixos({ stateVersion })` | NixOS base with flakes, nixpkgs, host platform, hostname, and Home Manager wiring |
| `platforms.darwin({ stateVersion, homebrew })` | nix-darwin base with flakes, nixpkgs, hostname, Home Manager, and optional nix-homebrew module |
| `account("adrifer", opts)` | `home.home.*`, `users.users.*` or `darwin.users.users.*`, shell, admin groups, optional WSL default user |
| `profile("dev", [...])` | Resolves recursively to child fragments; no backend-specific output |
| `services.enable("openssh", opts)` | `nixos.services.openssh = { enable = true; ... }` |
| `systemd.service("name", opts)` | `nixos.systemd.services.name = opts` |
| `systemd.timer("name", opts)` | `nixos.systemd.timers.name = opts` |
| `firewall.tcp(80, 443)` | `networking.firewall.allowedTCPPorts = [ 80 443 ];` |
| `home.env(vars)` | `home.sessionVariables.*` inside the Home Manager module |
| `home.path(paths)` | `home.sessionPath` inside the Home Manager module |
| `home.configFile(name, opts)` | `xdg.configFile.name = opts` inside the Home Manager module |
| `home.program("starship", opts)` | `programs.starship = { enable = true; ... }` inside the Home Manager module |
| `home.service("syncthing", opts)` | `services.syncthing = { enable = true; ... }` inside the Home Manager module |
| `nix.gc({ olderThan })` | `nix.gc` settings for NixOS |

## Nix expression namespace

The backend treats all `NixExpr` values from `nix.*` as atomic expressions:

```ts
nix.pkg("zsh")                    // pkgs.zsh
nix.str`${nix.pkg("git")}/bin/git` // "${pkgs.git}/bin/git"
nix.script`echo hello`             // '' echo hello ''
nix.lib.mkDefault("adrifer")       // lib.mkDefault "adrifer"
```

These values are not deep-merged as attrsets and are rendered verbatim wherever
the target option accepts a value.

## Provenance comments

Every section in generated Nix includes a comment indicating its source fragment:

```nix
# [fragments/work-sysctl.ts:8] Kernel tuning
boot.kernel.sysctl = { ... };
```

This enables `winix inspect provenance <path>` and visual debugging. Can be disabled with `winix apply --no-comments`.

## Lock file management

The `flake.lock` lives in the **project root** (committed to git). This ensures all hosts resolve identical package versions.

`winix apply` symlinks or copies the root lock into `.winix/out/flake.lock` so that `nixos-rebuild --flake .winix/out` uses the shared lock.

```bash
# Update all inputs:
winix update

# Update single input:
winix update nixpkgs

# Pin specific version:
winix update nixpkgs --to github:NixOS/nixpkgs/abc123
```

After updating, commit `flake.lock` to share the pin across all machines.

## Activation

`winix switch` delegates to the appropriate system tool:

| Platform | Activation command |
|---|---|
| NixOS | `sudo nixos-rebuild switch --flake .winix/out` |
| nix-darwin | `sudo darwin-rebuild switch --flake .winix/out` |
| Home Manager only | `home-manager switch --flake .winix/out` |

Variants via flags: `--boot`, `--test`, `--dry-activate`.

## Migration mode

Winix supports importing existing Nix modules during migration via `rawModule()`. A user can wrap their current dotfiles structure and incrementally convert modules to typed fragments without breaking anything.

## Validation

`winix check` can optionally invoke Nix validation:

```bash
winix check --nix-eval    # Run nix eval on generated output (catches Nix errors)
winix check --dry-build   # Run nix build --dry-run (full dependency check)
```

These are slower but catch issues that TypeScript validation alone cannot detect (e.g., missing packages, invalid module references).
